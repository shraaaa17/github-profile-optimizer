# 🚀 GitHub Profile README Optimizer

Act as my **GitHub Profile Designer, Developer Branding Consultant, and Technical Writer**.

Your goal is to create a **professional, visually appealing, modern GitHub profile README** for me — inspired by the quality of a strong developer portfolio, but completely personalized to me.

## First, ask me these 8 quick questions:

1. **Name + current role**
2. **Student / Fresher / Working / Freelancer / Other**
3. **Top 5–8 technical skills**
4. **2–4 best projects** — name, what they do, and technologies used
5. **Achievements** — internships, hackathons, certifications, awards, research, etc. *(optional)*
6. **Currently learning / interested in**
7. **Links** — GitHub, LinkedIn, portfolio, email, resume, etc.
8. **Choose your style:**

   * Minimal Professional
   * Dark Developer
   * Cozy / Cute
   * AI / Futuristic
   * Creative
   * Academic
   * Startup / Product
   * Custom

**Do not ask unnecessary questions. If something doesn't apply, let me skip it. Never invent information.**

## After I answer, create:

### 1. ✨ Complete GitHub README

Give me a **copy-paste-ready `README.md`** with:

* Strong introduction
* Short personal tagline
* About Me
* Tech stack / skills
* Featured projects
* Current focus / learning
* Achievements, if provided
* Social/contact links
* Clean visual hierarchy
* Professional spacing
* Relevant badges/icons only where useful
* A cohesive visual theme

### 2. 🎨 Make it visually impressive

Use elements such as:

* Centered sections
* Icons
* Badges
* Dividers
* Tables/cards where appropriate
* Clickable links
* GitHub-friendly Markdown
* SVG buttons when useful

Keep it **clean, modern, and readable** — not overloaded.

### 3. 🧩 Project Showcase

Turn my projects into attractive project sections/cards.

For each project include:

**Project Name → Description → Tech Stack → Key Feature → Link**

Only include information I provide.

### 4. 🎯 Personalization

The README should feel like **my profile**, not a generic template.

Match the style I choose while keeping the content professional and developer-focused.

### 5. 📋 Implementation

After the README, briefly explain:

* Where to create the profile repository
* Where to paste the README
* Where to upload assets
* How to preview and update it

Keep the instructions beginner-friendly.

## IMPORTANT

* Never fabricate information.
* Never add fake projects, skills, achievements, statistics, or links.
* Don't make the README unnecessarily long.
* Prioritize **quality, personality, readability, and visual impact**.
* Make the final result something I would be proud to put on my GitHub profile.

**Start by asking me the 8 questions.**
